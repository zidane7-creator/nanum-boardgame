🙋 자막 파일 올리는 방법 (관리자용)
  1. GitHub 자막 폴더 올리기 화면을 열어요 (사이트 관리자 계정으로 로그인).
  2. PPT 파일을 끌어다 놓고 아래 Commit changes를 눌러요. (한 파일 25MB까지)
  3. 1~2분 뒤 이 페이지에 자동으로 나타나요.
  4. 파일 이름 앞에 [찬양] [예배] [절기]처럼 대괄호로 분류를 붙이면 위쪽 분류 버튼으로 골라 볼 수 있어요. 예: [찬양] 주 품에.pptx
  5. 지우려면 GitHub의 자막 폴더에서 파일을 열고 휴지통 아이콘을 눌러요.

찬양 가사에는 저작권이 있을 수 있어요. 공개해도 되는 자막만 올려 주세요.
